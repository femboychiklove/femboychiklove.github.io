# 🔢 Rename Batch

**Массовое переименование файлов с автоматической нумерацией.**

## ✨ Возможности

- 🔄 Массовое переименование файлов с номерами
- 🔍 Фильтр по расширениям (jpg, png, txt и др.)
- 👁 Предпросмотр перед переименованием
- ↩️ Отмена последней операции
- 📁 Встроенный браузер папок (без системных окон)
- 🗑️ Удаление, создание, копирование и перемещение файлов
